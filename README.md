# firelight-repo

IReader plugin repository index for **Firelight** (StoryGraph Sync), an unofficial plugin that syncs IReader reading progress to StoryGraph.

This repo only holds the repository index (`index.json`) and release binaries that IReader's Feature Store fetches directly — it's kept separate from the plugin's source code, which stays private.

## Install

In IReader: Settings -> Repository -> add repository URL:

```
https://raw.githubusercontent.com/NinethSleep/firelight-repo/main/index.json
```

Then find "StoryGraph Sync" in the Feature Store and install it.
